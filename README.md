\# Video-Game-Sales-Statistical-Analysis



Statistical analysis and regression modeling of video game sales using Python (`pandas`, `SciPy`, `statsmodels`).



\## Overview

This project explores global video game sales (`Video\_Games.csv`) using:

\- \*\*Distribution inspection \& two-sample t-test\*\* comparing global sales between 2003 and 2013 (with Q-Q plots).

\- \*\*One-way ANOVA\*\* testing differences in mean sales across platforms.

\- \*\*Multiple linear regression (OLS)\*\* evaluating the relationship between `Global\_Sales` and variables such as `Platform`, `Year\_of\_Release`, `Publisher`, `Genre`, `Critic\_Score`, and `Rating`.



\## Requirements

\- Python 3.x

\- `numpy`, `pandas`, `scipy`, `matplotlib`, `statsmodels`



\## Usage

Place `Video\_Games.csv` in the project directory and open `project\_statics.ipynb` in Jupyter Notebook or VS Code to run all cells (or convert it to a `.py` script and run `python project\_statics.py`).
